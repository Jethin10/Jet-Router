11:Tad7,# 🏠 Localhost Deployment

Run Jet Router on your local machine for development and personal use.

---

## 📦 Installation

Install Jet Router globally via npm:

```bash
npm install -g jet-router
```

**Requirements:**
- Node.js 20 or higher
- npm 9 or higher

---

## 🚀 Starting the Server

Start Jet Router with a single command:

```bash
jet-router
```

The dashboard will automatically open in your browser at `http://localhost:3000`

**Default Configuration:**
- **Dashboard**: `http://localhost:3000`
- **API Endpoint**: `http://localhost:20128/v1`
- **Data Directory**: `~/.jet-router`

---

## 🔧 Configuration

### Custom Data Directory

Set a custom data directory using environment variable:

```bash
DATA_DIR=/path/to/data jet-router
```

### Custom Port

The API port (20128) and dashboard port (3000) are configured in the application. To change them, you'll need to modify the source code or use environment variables if supported.

---

## 🛑 Stopping the Server

Press `Ctrl+C` in the terminal where Jet Router is running.

```bash
# In the terminal running jet-router
^C  # Press Ctrl+C
```

The server will gracefully shut down and save all data.

---

## 🔄 Restarting the Server

Simply run the start command again:

```bash
jet-router
```

All your configurations, API keys, and combos are preserved in the data directory.

---

## 📊 Updating Jet Router

Update to the latest version:

```bash
npm update -g jet-router
```

Check your current version:

```bash
npm list -g jet-router
```

---

## 🔍 Troubleshooting

### Port Already in Use

If port 20128 or 3000 is already in use:

```bash
# Find process using the port (macOS/Linux)
lsof -i :20128
lsof -i :3000

# Kill the process
kill -9 <PID>
```

### Permission Errors

If you encounter permission errors during installation:

```bash
# Use sudo (not recommended)
sudo npm install -g jet-router

# Or fix npm permissions (recommended)
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

### Data Directory Issues

If the data directory is not accessible:

```bash
# Check permissions
ls -la ~/.jet-router

# Fix permissions
chmod 755 ~/.jet-router
```

---

## 📁 Data Directory Structure

```
~/.jet-router/
├── db.json           # Main database (providers, combos, settings)
├── logs/             # Application logs
└── cache/            # Temporary cache files
```

**Backup Your Data:**

```bash
# Backup
cp -r ~/.jet-router ~/.jet-router.backup

# Restore
cp -r ~/.jet-router.backup ~/.jet-router
```
